# Privacy Policy - CapCut Project Assistant

Last updated: September 18, 2026

CapCut Project Assistant is a desktop application for organizing, importing, and exporting CapCut projects and presets.

## Data accessed

When authorized by the user, the application may access local files selected by the user, the name and email of the Google account used for connection, and files created by the application in the Google Drive folder selected by the user.

## Google Drive

Google Drive connection is optional. The application uploads a project or preset only when the user selects a folder and enables synchronization. Files are sent directly to the Google Drive account or folder authorized by the user.

The application does not sell data, show advertising, or share information with third parties for commercial purposes. OAuth tokens are stored locally on the user's computer.

## Storage and deletion

Organization preferences are stored locally. The user can disconnect Google at any time and delete uploaded files directly from Google Drive.

## Security

The application uses OAuth 2.0 and requests only the permission needed to create and manage application files (drive.file). The application never receives a Google password.
